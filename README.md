# misc-troubleshooting

一些无法归类的问题的排查与解决记录。网络、代理、DNS、系统、软件、播放器等，凡是「不值得单独开一个仓库」的问题，都放在这里。

## 原则

- 每个问题一篇 Markdown，放在对应分类目录下。
- 统一记录：**症状 → 环境 → 诊断 → 根因 → 解决 → 复原 → 验证**。
- 不写入任何密码、订阅地址、节点信息、私有 IP、账号等敏感内容。
- 解决方案必须可复原，并写明复原步骤。
